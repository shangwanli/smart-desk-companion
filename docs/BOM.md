## 三、电缆连接

全部用焊锡焊接，走铜丝或裸线，不用杜邦线排针，裸露走线增加科技感。

## 四、引脚总览

```
ESP32-C3 Super Mini GPIO 分配:

  ┌──────────────────────────┐
  │  GPIO 0  → IN1  (方向)   │  L298N
  │  GPIO 1  → IN2  (方向)   │  L298N
  │  GPIO 2  → IN3  (方向)   │  L298N
  │  GPIO 3  → IN4  (方向)   │  L298N
  │  GPIO 4  → BCLK (I2S)   │  INMP441 + MAX98357
  │  GPIO 5  → WS   (I2S)   │  INMP441 + MAX98357
  │  GPIO 6  → DIN  (I2S)   │  INMP441
  │  GPIO 7  → DOUT (I2S)   │  MAX98357
  │  GPIO 8  → SDA  (I2C)   │  OLED
  │  GPIO 9  → SCL  (I2C)   │  OLED
  │  GPIO 10 → ENA  (PWM)   │  L298N 左轮
  │  GPIO 20 → (保留)       │  无 ADC，暂不用
  │  GPIO 21 → ENB  (PWM)   │  L298N 右轮
  └──────────────────────────┘

  12 个 GPIO 已使用，GPIO20 空闲。
⚠ ESP32-C3 ADC 仅在 GPIO0-5，GPIO20 不支持 ADC。
如需电池检测：外接 ADS1115 (I2C ADC) 挂 OLED 同一条 I2C 总线。
```
